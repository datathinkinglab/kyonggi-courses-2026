## 이 과제에서 배우고 평가하는 것

궁금한 점을 분석 가능한 질문으로 바꾸고, AI에게 필요한 처리를 명확하게 요청한 뒤, 결과가 맞는지 확인하는 것이 목표입니다. **문법을 외우거나 코드를 혼자 직접 작성할 필요는 없습니다.** 코드가 어떤 자료를 사용했고 무엇을 계산했는지 설명하며, 결과를 믿을 근거를 남기세요.

기본 흐름은 **문제 설명, 프롬프트로 요청, Colab 실행, 결과 확인, 필요한 수정 요청**입니다. 강의의 프롬프트와 코드를 참고해도 됩니다. 다만 자신의 질문에 맞게 바꾼 조건과 판단 근거를 설명해야 합니다.

## 과제 상황과 공통 질문

학교 식당에서 방문자에게 대기시간을 안내하려고 합니다. 담당자는 “평균 대기시간 하나만 알려주면 충분하다”고 생각합니다. 제공한 자료를 AI와 함께 분석해 어떤 정보를 함께 안내해야 하는지 제안하세요. 분석 결과가 맞는지 확인한 근거도 제시하세요.

**공통 질문:** 이 자료에서 평균 대기시간 하나만 안내하면 충분할까요? 어떤 정보를 함께 안내해야 할까요?

공통 질문과 함께 **자신이 정한 탐색 질문 1개**를 추가하세요. 예를 들어 시간대별 대기시간 분포나 특정 대기시간 이상인 방문을 살펴볼 수 있습니다. 제공된 변수로 답할 수 있는 질문을 선택하고 그 이유를 적습니다.

## 공통 자료와 시작 방법

전원에게 같은 **교육용 가상 식당 방문 자료 120건**을 제공합니다. 실제 학교 식당의 조사 결과가 아닙니다. 별도의 자료 수집이나 유료 AI 사용은 필요하지 않습니다.

| 변수 | 의미 | 척도·기록 규칙 |
| --- | --- | --- |
| visit_id | 방문 기록 식별자 | 명목, 한 행은 방문 한 건 |
| time_slot | 방문 시간대 | 명목, 점심 초반·점심 혼잡·저녁 |
| wait_minutes | 주문 후 음식 수령까지 기다린 시간(분) | 비율, 0분은 유효값·빈칸은 미응답 |
| satisfaction | 해당 방문의 만족도 1~5 | 순서, 1=매우 불만족·5=매우 만족·빈칸은 미응답 |

**자료 묶음의 파일**

- cafeteria_wait_120.csv: 분석에 사용할 전체 자료.
- validation_12.csv: 전체 자료의 M001~M012만 발췌한 손계산·손그림 확인용 자료. 전체 자료에 다시 합치지 않습니다.
- DATA_DICTIONARY.md: 자료 출처·단위·허용값·처리 원칙.
- EDA_midterm_start.ipynb: 자료 불러오기와 기록 틀을 담은 시작 노트북.
- review_draft.ipynb / review_draft.py: 검토할 분석 초안. **의도적인 처리 문제를 포함하며 정답 코드가 아닙니다.**
- report_template.md: 보고서 구성과 제출 점검표.

자료 묶음을 내려받아 자료 사전을 먼저 읽으세요. Colab에서 시작 노트북을 열어 자신의 사본을 저장하고 준비 셀부터 실행합니다. 준비 셀은 공개된 동일 CSV를 불러오므로 별도의 데이터 업로드 없이 시작할 수 있습니다. 분석은 자신의 프롬프트로 AI에게 요청하고, 받은 코드를 노트북에 붙여넣어 실행하세요. 새 AI 대화를 시작할 때는 자료 사전과 앞서 만든 코드도 함께 제공합니다.

## 수행 과제

### 1. 질문과 자료 이해

공통 질문과 자신의 탐색 질문 1개를 적고, 한 행의 의미·변수의 척도·단위·0과 미응답의 차이를 설명하세요. 전체 방문 수와 시간 유효·결측 수를 확인합니다. 행 수를 학생 수로 해석하지 않습니다.

### 2. 분석 명세와 AI 요청

**자료 출처·대상 변수·결측 처리·출력 형태**를 포함한 프롬프트를 작성하세요. 원자료 보존, 평균의 분모, 큰 값 처리, 정렬·표시 단위·구간 경계를 구체적으로 정합니다. 주요 프롬프트 원문·실제 AI 응답·수정 요청·수정 이유를 노트북에 남기세요.

미응답을 자동으로 0으로 채우지 않습니다. 만족도만 미응답인 방문의 유효 대기시간은 시간 분석에 포함합니다. 긴 대기시간은 크다는 이유만으로 삭제하지 않습니다. 실제 학생·식당 전체에 대한 인과적 결론을 내리지 않습니다.

### 3. 표와 그림 생성

다음 결과를 Colab에서 생성하세요.

1. 전체 및 시간대별 **전체 방문 수·시간 유효 수·시간 결측 수·평균 대기시간** 요약표.
2. validation_12.csv의 유효 시간으로 만든 **줄기와 잎 그림**. 키·단위를 적고 반복값·빈 줄기·잎 수를 확인합니다.
3. 전체 유효 시간에서 **구간 폭을 바꾼 히스토그램 3개**. 자료와 전체 표시 범위는 유지하고 폭을 비교합니다.
4. 전체 유효 시간에서 **폭은 같게 두고 시작점만 바꾼 히스토그램 2개**.
5. 설정을 바꿔도 유지되는 관찰과 달라지는 인상의 설명.

그림마다 단위·유효 수·결측 수·구간 경계와 경계 포함 규칙을 명시합니다. **0분과 긴 대기시간을 포함해 모든 유효값을 담는 경계**를 선택하세요. 비교 그림의 축 범위를 맞추고 빈도 합계·범위 밖 개수를 확인합니다. 3개 비교 그림과 2개 비교 그림은 각각 한 묶음으로 배치해도 됩니다.

### 4. 검토용 초안 진단과 수정

제공된 review_draft를 실행하고 다음 세 처리가 원래 목적에 적절한지 검토하세요.

- **처리 A:** 시간 미응답을 0분으로 바꾼 전체 평균.
- **처리 B:** 어떤 열이든 미응답인 방문을 먼저 제외한 시간대별 요약.
- **처리 C:** 0~40분 경계만 사용한 히스토그램.

각각 **원래 목적, 초안의 문제, 영향을 받은 ID·분모·평균 또는 그림, AI에게 보낸 수정 요청, 수정 결과, 확인 근거**를 기록합니다. 평균이 우연히 같더라도 사용한 방문과 분모가 달라졌는지 확인하세요. 학생이 사용하는 AI에서 일부러 오류가 나올 때까지 요청을 반복할 필요는 없습니다. 제공한 공통 초안을 기준으로 진단합니다.

### 5. 검증 3종 세트

| 방법 | 필수 수행 |
| --- | --- |
| 손계산 대조 | validation 12건의 유효 수·합계·평균을 직접 계산합니다. 구간 [0,10), [10,20), [20,30), [30,40), [40,120]의 빈도도 직접 셉니다. 마지막 구간만 오른쪽 끝을 포함합니다. 계산기는 사용할 수 있고 과정·분모를 기록합니다. |
| 대안 방법 교차확인 | 요약표의 평균을 유효값 목록의 합계÷개수로 비교하거나, 구간 조건을 직접 적용해 히스토그램 빈도를 다시 셉니다. |
| 극단 사례 투입 | 원자료와 분리한 시험 자료에 전부 결측·단일값·구간 경계값을 각각 넣어 예상 반응과 실제 결과를 비교합니다. |

각 검증에서 **실행 전 예상값과 실제 결과**를 구분하고 일치·불일치의 이유를 적습니다. “AI에게 다시 물었더니 맞다고 했다”만으로는 검증을 인정하지 않습니다. Matplotlib의 hist와 NumPy의 histogram은 집계 구현을 공유하므로 그 두 결과의 일치만으로 대안 경로 검증을 마무리하지 않습니다.

### 6. 최종 안내안과 한계

처음 질문에 답하는 **식당 대기시간 안내 문구 2~3문장**을 작성하고 표·그림으로 근거를 설명하세요. 이 가상 자료에서 관찰한 사실, 추가로 확인할 점, 실제 학생·식당 전체로 일반화할 수 없는 이유를 구분합니다.
