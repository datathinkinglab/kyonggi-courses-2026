# 기말 발표·성적 확인 시스템 설치 안내 (자료탐색방법론)

구성 파일은 두 개입니다.

| 파일 | 역할 | 놓는 곳 |
|---|---|---|
| `final-showcase.html` | 학생들이 보는 사이트 (조별 자료, 자료 등록, 평가, 내 성적) | 저장소 `docs/eda/` (GitHub Pages) — 이미 반영됨 |
| `Code.gs` | 저장소 역할을 하는 Apps Script (구글 시트 + 드라이브) | 구글 스프레드시트의 Apps Script |

강의 홈의 중간고사·기말과제 카드와 기말과제 안내 페이지에 이 사이트로 가는 링크가 들어가 있습니다. `API_URL` 을 넣기 전까지 사이트는 학생에게 "준비 중" 화면만 보여 줍니다.

## 1. 구글 시트 준비 (약 5분)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: `자료탐색방법론_기말발표`)
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 전체를 붙여넣은 뒤 저장합니다.
4. 상단 함수 선택에서 **setup** 을 고르고 **실행** 합니다. 권한 승인 창이 나오면 본인 계정으로 허용합니다.
   - "확인되지 않은 앱" 경고가 나오면 **고급 > (프로젝트 이름)(으)로 이동** 을 누릅니다. 본인이 만든 스크립트라서 나오는 안내입니다.
5. 시트로 돌아가면 `명단`, `설정`, `조정보`, `자료`, `발표평가`, `동료평가`, `중간고사`, `기말고사`, `성적열람기록` 시트가 만들어져 있습니다.
6. 중간고사 성적을 붙여넣습니다 (아래 4장).
7. 메뉴 **기말발표 관리 > 명단 학번 채우기** 를 누르면 `명단` 의 빈 학번이 중간고사 시트의 학번으로 채워집니다. 중간고사 시트에 없는 학생(미제출자 등)은 안내창에 이름이 나오니 직접 입력하세요.
   - 조와 이름은 기말과제 안내의 11개 조 42명으로 미리 들어가 있습니다. 조가 없는 수강생도 `조` 칸을 비운 채 추가하면 로그인과 성적 확인이 됩니다.

## 2. 웹 앱 배포

1. Apps Script 화면 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
2. 유형은 **웹 앱**, 실행 계정은 **나**, 액세스 권한은 **모든 사용자** 로 설정하고 배포합니다.
3. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

코드를 나중에 수정하면 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전** 으로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

## 3. 사이트에 연결

1. 저장소의 `docs/eda/final-showcase.html` 위쪽 `const API_URL = '';` 따옴표 안에 웹 앱 URL을 붙여넣고 커밋합니다. (GitHub 웹에서 파일을 열고 연필 아이콘으로 바로 고칠 수 있습니다.)
2. 다른 배포처(`courses/exploratory-data-analysis/dist/`)를 함께 쓰신다면 그쪽 파일도 똑같이 고칩니다.
3. 주소: `https://datathinkinglab.github.io/kyonggi-courses-2026/eda/final-showcase.html`
   - 성적 화면 바로가기: `…/final-showcase.html#grades`

연결 전에 화면을 보고 싶으면 주소 끝에 `?demo=1` 을 붙이세요. 예시 데이터로 모든 화면을 눌러 볼 수 있고, 아무것도 저장되지 않습니다.

## 4. 성적 넣기

### 중간고사

`중간고사` 시트의 머리글은 채점 엑셀(`자료탐색방법론_중간고사_채점결과.xlsx`)의 `채점결과` 시트와 **같은 열 순서**입니다.

1. 엑셀 `채점결과` 시트에서 학생 행(5행부터 마지막 학생까지, A~Q열)을 복사합니다. 아래쪽 평균 행은 빼세요.
2. 구글 시트 `중간고사` 시트의 **A2** 를 선택하고 **값만 붙여넣기**(Ctrl+Shift+V)합니다.
3. 원점수 75점 미만 학생은 엑셀 `상세피드백` 시트의 해당 학생 블록을 복사해 마지막 열 `항목별 상세 피드백` 칸에 붙여넣습니다. (칸을 더블클릭한 뒤 붙여넣으면 줄바꿈이 유지됩니다.)
4. 메뉴 **기말발표 관리 > 성적 시트 점검** 으로 학생 화면에 무엇이 보이고 무엇이 숨겨지는지 확인합니다.

### 기말고사

`기말고사` 시트에는 기말과제 평가 기준에 맞춘 머리글이 들어 있습니다. 동료평가 점수는 `동료평가_집계` 의 `평균 환산(30)` 값을 옮기면 됩니다. 반영 방식이 다르면 머리글을 바꿔도 됩니다.

### 머리글 규칙 (두 시트 공통)

시트 1행의 머리글을 읽어 화면을 만듭니다. 열을 추가하거나 순서를 바꿔도 됩니다.

| 머리글 | 학생 화면 |
|---|---|
| `학번` (필수), `이름` | 본인 확인용. 표시하지 않음 |
| `(숫자)` 로 끝남 — 예: `① 질문 설계 (15)` | 항목 점수와 막대. 괄호 안 숫자가 만점 |
| `최종점수`, `총점`, `원점수`, `합계`, `환산`, `반영` 포함 | 합계 점수. 최종점수 > 총점 > 원점수 순으로 큰 숫자로 표시 |
| `감점` 포함 | 감점 표시. `감점률` 이고 값이 1 이하이면 %로 표시 |
| `피드백` 포함 | 피드백 글. 첫 번째는 펼쳐서, 나머지는 접어서 표시 |
| `※` 로 시작하거나 `교수자`·`비공개`·`메모` 포함, `No`·`순위`·`조`·`메일 수신시각`·`채점 대상본` | **표시하지 않음** |
| 그 밖의 열 (예: `제출구분`) | 값이 있으면 작은 꼬리표로 표시 |

학생에게 보이면 안 되는 내용은 반드시 `※` 로 시작하는 열에 적으세요.

## 5. 운영 일정에 맞춰 여닫기

`설정` 시트의 `값` 열을 `Y` 또는 `N` 으로 바꾸면 즉시 적용됩니다.

| 항목 | 처음 값 | 언제 바꾸나 |
|---|---|---|
| 자료등록 | Y | 12/7 오픈. 발표 후 자료를 고정하려면 N |
| 발표평가 | N | 12/14 발표 시작 때 Y, 마감 시 N |
| 동료평가 | N | 12/14 발표 후 Y, 마감 시 N |
| 결과공개 | N | 조별 발표평가 평균을 사이트에 보여 주려면 Y |
| 중간성적공개 | N | 중간고사 점수·피드백을 공개할 때 Y |
| 기말성적공개 | N | 기말고사 점수·피드백을 공개할 때 Y |
| 성적통계 | Y | 성적 화면에 수강생 평균·중앙값을 함께 보여 줌. 응시자가 5명 미만이면 자동으로 숨김 |

공개 전에 꼭 **성적 시트 점검** 을 한 번 실행하세요.

## 6. 채점에 활용하기

시트 메뉴 **기말발표 관리 > 집계 갱신** 을 누르면 두 시트가 새로 계산됩니다.

- `발표평가_집계`: 조별로 받은 평가 수, 항목별 평균, 총점 평균(25점)과 100점 환산
- `동료평가_집계`: 학생별 받은 평가 수, 평균 환산 점수(30점), 최저·최고, 점검 필요 표시, 본인 제출 여부
  - `확인 어려움` 으로 표시된 응답은 평균에서 빼고 건수만 보여 줍니다.
  - 평가 누락, 근거 부족, 평가자 간 차이가 15점 이상이면 `점검 필요` 에 표시됩니다. 안내문대로 교수자가 최종 확정하면 됩니다.

원자료는 `발표평가`, `동료평가` 시트에 한 줄씩 쌓이며, 같은 학생이 다시 제출하면 기존 줄을 덮어씁니다.

## 알아둘 점

- **본인 확인**: 이름과 학번이 `명단` 과 일치해야 로그인됩니다. 5회 틀리면 10분간 잠기고, 로그인은 12시간 뒤 만료됩니다. 학번은 사이트에 노출되지 않습니다.
- **성적 보호**: 서버는 로그인한 학생 본인의 행만 돌려주고, 숨김 열은 아예 보내지 않습니다. 누가 언제 성적을 조회했는지 `성적열람기록` 시트에 남습니다. 다만 같은 반 학생의 이름과 학번을 아는 사람은 그 학생으로 로그인할 수 있으니, 학생들에게 학번을 공유하지 말라고 안내해 주세요.
- **권한**: 자료 등록·삭제는 자기 조만, 발표 평가는 자기 조를 제외한 조만, 동료평가는 자기 조 팀원만 할 수 있습니다. 동료평가 응답은 본인 외에는 사이트 어디에도 표시되지 않습니다.
- **파일**: 25MB 이하, 드라이브의 `자료탐색방법론_기말발표_업로드/○조` 폴더에 저장되고 "링크가 있는 모든 사용자 보기"로 공유됩니다. 더 큰 파일은 링크로 등록하게 됩니다. `.ipynb` 파일에는 "Colab에서 열기" 버튼이 붙습니다.
- **발표 평가 항목**: 기말과제 평가 기준표의 5개 항목을 1~5점으로 구성했습니다. 항목이나 척도를 바꾸려면 `Code.gs` 위쪽 `TEAM_CRITERIA`, `TEAM_SCALE` 을 고치고 다시 배포하면 됩니다. 단, 평가를 받기 시작한 뒤에는 바꾸지 마세요.
- **검증 범위**: 화면은 데모 모드로, 서버 로직은 가상 시트 환경에서 시험했습니다. 실제 구글 환경에서의 배포·파일 업로드·성적 조회는 설치 후 본인을 명단에 임시로 넣어 한 번씩 확인해 주세요.
