기존 강의계획의 9주차 제출 안내 대신, 이번 과제는 위 마감 일시를 기준으로 제출합니다.

1. 과제 목적과 핵심 질문

1~4주차에서 배운 문제 정의, AI 활용, 데이터 정리·분석·시각화, 결과 검증을 기업 현황분석에 적용합니다. 조별로 같은 기업을 선정하되, 보고서는 각자 작성합니다.

우리 조가 선정한 기업은 현재 어떤 상태이며, 자료를 근거로 어떤 문제 후보를 제시할 수 있는가?

이번 과제의 중심은 기업의 현황을 근거로 설명하는 것입니다. 해결전략과 실행계획은 이후 기말 프로젝트에서 발전시킵니다.

2. 수행 내용

  1. 기업 소개와 개인 분석 질문 1개

    주요 사업·산업을 간단히 소개하고, 자신이 확인할 질문과 선정 이유를 설명합니다. 예: “최근 매출 증가에 비해 수익성이 개선되지 않은 이유를 확인할 수 있는가?”

  2. 핵심 지표 3개 이상과 자료 정리

    분석 질문에 맞는 매출액, 영업이익률, 부채비율 등의 지표를 선택합니다. 최근 연속 3개년 자료를 권장하며, 확보가 어렵다면 사용 가능한 기간과 이유를 명시합니다. 지표별 출처, 기준 기간, 단위, 산식과 분모, 결측치·자료 정리 기준을 기록합니다. 없는 수치는 임의로 만들지 않습니다.

  3. 표·그래프 3개 이상과 핵심 발견 2개 이상

    수준·변화·추세를 분석 질문에 연결하여 설명합니다. 표와 그래프는 합계 3개 이상입니다. 경쟁사 비교, 추론통계, 머신러닝은 질문과 자료에 적합할 때 선택적으로 활용합니다.

  4. 핵심 수치 3개 검증

    원문 대조 또는 직접 재계산을 수행합니다. 원문 위치, 계산식, 검증 결과와 수정 내용을 기록하고, 본문·표·그래프의 숫자가 같은지 확인합니다.

  5. 문제 후보 1개와 추가 확인 계획

    관찰된 사실, 가능한 원인 가설, 더 필요한 자료와 확인 방법을 구분하여 제시합니다. 자료가 보여주는 범위를 넘어 인과관계를 단정하지 않습니다.

1~4주차 고객 이탈 실습 데이터는 합성 자료입니다. 실제 기업 자료처럼 사용하지 않으며, 선정 기업의 공개 자료와 질문에 맞는 분석을 수행합니다.

3. 보고서 구성과 제출물

보고서 본문 4~6쪽으로 작성합니다. 표지·참고문헌·부록은 분량에서 제외합니다.

  1. 경영진 요약 1쪽: 질문, 핵심 발견, 문제 후보와 한계
  2. 기업 소개와 개인 분석 질문
  3. 자료 출처, 지표 정의와 분석 방법
  4. 표·그래프와 핵심 발견
  5. 문제 후보, 분석의 한계와 추가 확인 계획
  • 필수: 보고서 PDF
  • 필수: 사용 데이터와 분석 코드 또는 계산 내용을 확인할 수 있는 파일
  • 필수: 핵심 수치 3개 검증 기록
  • 필수: 대표 AI 프롬프트 2~3개와 본인이 검토·수정한 내용
  • 필수: 개인 수행 범위와 동료 피드백 및 반영 내용
  • 선택: 대시보드·웹 앱·저장소 링크

검증 기록, AI 활용 기록, 개인 수행 범위와 피드백은 보고서 부록에 포함해도 됩니다. 웹 배포 여부 자체가 평가의 중심은 아닙니다.
