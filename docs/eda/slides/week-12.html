근거리에서는 빠른배송의 지연 비율이 높습니다

같은 근거리 주문끼리 비교하면, 전체에서 보았던 순서와 달라집니다.

  • 빠른배송근거리 70건 중 지연 7건 → 10%
  • 일반배송근거리 5건 중 지연 0건 → 0%
  • 관찰한 차이빠른배송의 지연 비율이 10%p 높습니다.
  • 함께 볼 정보일반배송의 근거리 표본은 5건으로 작습니다. 0%를 절대적인 안전으로 해석하지 않습니다.

0/5는 ‘관찰한 다섯 건에서 지연이 없었다’는 뜻입니다.

두 방식의 거리 구성이 다릅니다

한 칸은 주문 한 건입니다. 밝은 파랑은 근거리, 황토색은 원거리를 나타냅니다.

  • 빠른배송의 구성80건 중 근거리 70건 → 근거리 비중 87.5%
  • 일반배송의 구성20건 중 근거리 5건 → 근거리 비중 25%
  • 자료에서 나타난 특징근거리의 지연 비율은 두 방식 모두 원거리보다 낮습니다.
  • 전체 비율에 반영되는 것빠른배송에는 지연 비율이 낮은 거리대의 주문이 많이 들어 있습니다.

전체 비율은 층별 비율의 가중평균입니다

각 거리대의 비율에 그 거리대가 차지하는 주문 비중을 곱한 뒤 더합니다.

빠른배송 · 근거리 비중 87.5%

0.875 × 10%+ 0.125 × 50%= 15%

근거리 70건·원거리 10건의 구성이 전체 비율에 반영됩니다.

일반배송 · 원거리 비중 75%

0.25 × 0%+ 0.75 × 40%= 30%

근거리 5건·원거리 15건의 구성이 전체 비율에 반영됩니다.

가중치는 지연 건수가 아니라 각 거리대의 전체 주문 수로 정합니다.

두 방식에는 서로 다른 가중치가 적용됩니다. 층별 비율을 단순 평균하지 않습니다.

거리 구성을 같게 놓으면 어떻게 보일까요?

두 방식에 동일한 근거리 비중을 적용해 보세요. 기본값은 전체 표본의 구성인 75%입니다.

슬라이더를 움직이거나 방향키로 조절하세요. 원거리 비중 = 100% − 근거리 비중.

빠른배송20%
일반배송10%

0.75×10% + 0.25×50% = 20% / 0.75×0% + 0.25×40% = 10%

  • 관찰 비율은 그대로실제 표의 전체 비율은 15%·30%입니다. 이 값을 덮어쓰지 않습니다.
  • 공통 구성비에 따른 비교거리 구성을 통일하여 다시 계산한 요약값을 표준화 비율이라고 합니다.
  • 75%를 택한 이유전체 100건 중 근거리 주문이 75건이기 때문입니다. 다른 목표 집단이면 다른 가중치를 쓸 수 있습니다.
  • 이 예시의 특징어떤 공통 구성비에서도 빠른배송이 10%p 높습니다. 두 층의 차이가 모두 10%p이기 때문입니다.

조건을 통일한 계산도 인과적 효과를 자동으로 보장하지는 않습니다.

0 / 5

0 / 0

미분류

거리는 배송 방식과 지연의 비교에 함께 볼 조건입니다

배송 방식을 배정하는 과정과 지연이 발생하는 과정을 함께 생각해 봅니다.

  • 혼재변수 후보비교하는 집단의 구성과 결과의 차이를 함께 설명할 수 있는 변수입니다.
  • 이 예시에서 확인한 것방식별 거리 구성비가 다르고, 거리대별 지연 비율도 다릅니다.
  • 맥락으로 더 확인할 것거리가 배송 방식 선택 이전에 정해졌는지, 배정 기준과 어떤 관계인지 확인합니다.
  • 추가 후보시간대·날씨·주문량·기사 배정 등도 자료와 업무 과정에 근거해 검토합니다.

층화 후 방향이 바뀌었다는 사실만으로 인과 구조가 확정되는 것은 아닙니다.

전체 운영 현황을 묻는다면

“지금 처리한 모든 주문에서 방식별 지연 비율은 얼마였는가?”

빠른배송 15% · 일반배송 30%

실제 배정된 주문 구성까지 포함한 전체 현황입니다.

같은 조건의 비교를 묻는다면

“같은 거리대 안에서 방식별 지연 비율은 얼마였는가?”

근거리 10%·0% / 원거리 50%·40%

“배송 방식을 바꾸면 지연이 줄어드는가?”는 추가 조건과 연구 설계가 필요한 인과적 질문입니다.

전체 표를 버리거나 층별 표를 무조건 정답으로 삼지 않습니다.

참고 팝업 안에서 방향키를 눌러도 뒤의 슬라이드는 이동하지 않습니다. 모바일은 좌우로 쓸어 넘길 수 있으며, 긴 내용은 전체 읽기를 이용하세요. ‘동작 줄이기’를 켜면 호버 이동·등장 효과가 멈춥니다.

분모와 가중평균 복습

같은 12건이라도 전체 중 비중은 12/100=12%, 빠른배송 안의 지연 비율은 12/80=15%, 지연 주문 안에서 빠른배송의 비중은 12/18≈66.7%입니다.

배송 방식지연정시주문 수지연 비율
빠른배송12688015%
일반배송6142030%
합계188210018%

전체 지연 비율은 18/100=18%입니다. 방식별 비율을 주문 비중으로 가중평균하면 0.8×15%+0.2×30%=18%입니다. 단순 평균 22.5%는 두 방식의 주문 수가 다르다는 점을 반영하지 않습니다.

가상 자료와 분류 규칙

이 수업의 배송 자료는 교육용 가상 자료입니다. 11차수의 전체 건수에 거리대를 가상으로 추가한 것이며, 관측하지 않은 실제 거리를 복원한 자료가 아닙니다.

거리대배송 방식지연정시합계비율
근거리빠른배송7637010%
근거리일반배송0550%
원거리빠른배송551050%
원거리일반배송691540%

한 행은 주문 한 건입니다. 기본 자료에는 결측이 없으며, 근거리·원거리는 사전에 정한 범주라고 가정합니다. 기존 배송시간을 함께 사용할 때의 지연 기준은 30분 초과, 정시는 30분 이하입니다. 거리 미분류 주문이 생기면 지연 여부와 별개로 표시하고 전체·층별 분석의 포함 건수를 각각 보고합니다.

거리대별 손계산 해설

거리대배송 방식지연정시합계비율
근거리빠른배송7637010%
근거리일반배송0550%
원거리빠른배송551050%
원거리일반배송691540%

각 층에서 배송 방식별 전체 주문 수가 분모입니다. 근거리: 7/70=10%, 0/5=0%. 원거리: 5/10=50%, 6/15=40%입니다.

층별 건수를 더하면 빠른배송 지연 7+5=12, 정시 63+5=68, 일반배송 지연 0+6=6, 정시 5+9=14가 되어 전체 표를 복원합니다.

주문 수가 가중치가 되는 이유

빠른배송의 전체 비율을 분수로 써 보면 (7+5)/(70+10)입니다. 이를 (70/80)×(7/70)+(10/80)×(5/10)으로 나누면 각 항이 7/80, 5/80이 됩니다.

전체 비율 = Σ(층의 전체 주문 수 / 방식의 전체 주문 수) × 층별 지연 비율

일반배송도 (5/20)×(0/5)+(15/20)×(6/15)=6/20=30%입니다. 전체 표는 비율끼리 더하는 것이 아니라 건수를 더한 뒤 계산합니다. 반올림은 마지막 출력에서만 수행합니다.

심슨의 역설과 질문의 차이

이 예시에서는 빠른배송이 근거리·원거리 모두에서 지연 비율이 높지만, 전체에서는 낮습니다. 서로 다른 거리대별 비율과 방식별 구성비가 결합해 전체의 비교 방향이 달라진 것입니다.

모든 층에서 순서가 같아야 하는 것은 실제 자료의 전제가 아닙니다. 실제 자료에서는 층별 관계가 서로 다르거나, 방향은 유지되고 차이의 크기만 달라질 수도 있습니다. 역전 자체를 찾는 것보다, 집계가 어떤 질문에 답하는지 확인하는 것이 목적입니다.

0건·작은 표본·결측의 차이

0/5=0%는 다섯 주문에서 지연을 관찰하지 않았다는 뜻입니다. 모집단에서 지연 가능성이 없다는 뜻은 아닙니다. 근거리 일반배송 5건이라는 작은 분모를 함께 표시합니다.

0/0은 해당 층에 주문이 없다는 뜻으로 비율을 정의할 수 없습니다. 거리 결측은 주문은 존재하나 그 층을 모르는 경우입니다. 이를 근거리 또는 원거리에 임의로 넣거나 0으로 바꾸지 않습니다.

권장 문장: “근거리 일반배송 5건에서는 지연이 관찰되지 않았다. 표본 수가 작아 추가 자료에서 결과가 달라질 수 있다.”

공통 구성비와 직접 표준화

관찰 전체 비율은 실제 배정된 거리 구성에 따른 값입니다. 표준화 비율은 두 방식의 거리 구성을 같게 두고 비교하기 위해 계산한 값입니다.

전체 표본의 근거리 75건·원거리 25건을 공통 가중치로 쓰면 빠른배송은 0.75×10%+0.25×50%=20%, 일반배송은 0.75×0%+0.25×40%=10%입니다.

공통 근거리 비중을 w로 두면 빠른배송은 50−40w(%), 일반배송은 40−40w(%)입니다. 두 비율의 차이는 10%p로 일정합니다. 이 특징은 이 교육용 예시에 관한 것이며 일반적인 모든 자료에서 성립하지 않습니다.

가중치의 기준 집단을 명시하고, 이 계산을 인과적 효과의 확정으로 해석하지 않습니다.

층화 변수 선택과 인과 해석

혼재변수는 단순히 ‘추가로 넣는 변수’와 같지 않습니다. 비교 집단의 배정과 결과에 어떤 맥락으로 관련되는지 확인해야 합니다. 배송 거리의 경우 방식 선택 이전의 조건인지, 실제 배정 규칙에 사용되었는지 확인합니다.

관측된 자료에서 구성비와 결과가 다르다는 사실만으로 인과적 구조가 확정되는 것은 아닙니다. 결과 이후에 결정되는 변수나 중간 과정의 변수를 무조건 통제하면 질문이 달라지거나 잘못된 비교가 생길 수 있습니다.

수업에서는 “관련이 관찰되었다”, “이 조건 안에서 비율이 높았다”라고 표현합니다. “바꾸면 줄어든다”는 주장은 추가 교란 조건·표본 선택·연구 설계의 검토가 필요합니다.

실습 1 · 작성 프롬프트와 비교용 Python

작성 프롬프트
제시한 거리대×배송 방식별 지연·정시 건수로 고유 order_id를 가진 교육용 주문 100건을 만들어 줘. 열은 order_id, method, distance_group, late로 해 줘. 전체 및 거리대별 배송 방식×지연 여부 교차표와 방식 내 지연 비율을 구하고 각 비율에 분자·분모·단위를 표시해 줘. 층별 표의 합과 전체 표를 대조하고, 방식별 거리 구성비를 가중치로 전체 비율을 재계산해 줘. 자료에 없는 인과관계는 단정하지 마.

비교용 Python
import pandas as pd
import numpy as np

# 교육용 가상 배정: (거리대, 방식, 지연 건수, 정시 건수)
spec = [('근거리', '빠른배송', 7, 63),
        ('근거리', '일반배송', 0, 5),
        ('원거리', '빠른배송', 5, 5),
        ('원거리', '일반배송', 6, 9)]
rows = []
for distance, method, delayed, on_time in spec:
    for late, count in [('지연', delayed), ('정시', on_time)]:
        rows += [{'method': method, 'distance_group': distance,
                  'late': late} for _ in range(count)]
orders = pd.DataFrame(rows)
orders.insert(0, 'order_id', range(1, len(orders) + 1))
methods, statuses = ['빠른배송', '일반배송'], ['지연', '정시']
distances = ['근거리', '원거리']
def cross(frame):
    return pd.crosstab(frame['method'], frame['late']).reindex(
        index=methods, columns=statuses, fill_value=0)

overall = cross(orders)
strata = {d: cross(orders[orders.distance_group == d])
          for d in distances}
print('전체 빈도표\n', overall)
for label, tab in [('전체', overall), *strata.items()]:
    n = tab.sum(axis=1)
    print(label, '\n', pd.DataFrame({
        '지연': tab['지연'], '분모': n,
        '비율(%)': 100 * tab['지연'].div(n)}))

# 같은 자료를 직접 필터링하여 독립 확인합니다.
assert len(orders) == orders.order_id.nunique() == 100
assert overall.to_numpy().tolist() == [[12, 68], [6, 14]]
assert strata['근거리'].to_numpy().tolist() == [[7, 63], [0, 5]]
assert strata['원거리'].to_numpy().tolist() == [[5, 5], [6, 9]]
pd.testing.assert_frame_equal(strata['근거리'] + strata['원거리'], overall)
for d in distances:
    for m in methods:
        sub = orders[(orders.distance_group == d) & (orders.method == m)]
        assert sub['late'].eq('지연').sum() == strata[d].loc[m, '지연']

# 가중치는 지연 건수가 아니라 해당 층의 전체 주문 수입니다.
for m in methods:
    ns = np.array([strata[d].loc[m].sum() for d in distances])
    rates = np.array([strata[d].loc[m, '지연'] / ns[i]
                      for i, d in enumerate(distances)])
    weighted = np.average(rates, weights=ns)
    assert np.isclose(weighted, overall.loc[m, '지연'] / overall.loc[m].sum())
    standardized = np.dot([.75, .25], rates)
    print(m, '구성비:', ns / ns.sum(), '관찰:', weighted,
          '공통구성비 적용:', standardized)
assert orders['late'].eq('지연').sum() == 18
print('검산 완료: 전체 지연 비율 = 18/100 = 18%')

실행 후 고유 주문 수 100건, 지연 합계 18건, 전체 표 [[12,68],[6,14]], 공통 구성비 비율 20%·10%를 확인하세요. assert 문은 손계산한 확인값 및 다른 집계 경로와 대조하는 용도입니다.

실습 2 · 작성 프롬프트와 비교용 Python

작성 프롬프트
같은 교육용 주문 100건으로 전체·근거리·원거리의 방식별 지연 비율을 3개 패널에 그려 줘. 세 패널의 비율 축은 0~100%로 통일하고 분자/분모를 붙여 줘. 별도 그림에는 각 방식의 근거리·원거리 구성비를 100% 누적 막대로 표시해 줘. 근거리 75%, 원거리 25%라는 공통 가중치로 계산한 표준화 비율도 출력해 줘. 관찰 비율과 표준화 비율을 구분하고 계산 근거를 보여 줘.

비교용 Python
# 먼저 실습 1의 작성 프롬프트와 비교용 Python을 실행합니다.
import matplotlib.pyplot as plt
import numpy as np

# Colab 기본 글꼴에서도 읽히도록 그림 라벨은 영문으로 표시합니다.
names = ['Fast', 'Regular']
colors = ['#074c8c', '#e66b55']
fig, axes = plt.subplots(1, 3, figsize=(13, 4), layout='constrained')
for ax, (label, tab) in zip(axes, [('Overall', overall),
                     ('Near', strata['근거리']), ('Far', strata['원거리'])]):
    n = tab.sum(axis=1).to_numpy()
    late = tab['지연'].to_numpy()
    rates = 100 * late / n
    bars = ax.bar(names, rates, color=colors)
    ax.set(ylim=(0, 100), title=label, ylabel='Delayed orders (%)')
    ax.bar_label(bars, labels=[f'{r:g}% ({a}/{b})'
                              for r, a, b in zip(rates, late, n)], padding=4)
plt.show()

counts = np.array([[70, 10], [5, 15]]) # 행: Fast/Regular; 열: Near/Far
shares = 100 * counts / counts.sum(axis=1, keepdims=True)
fig, ax = plt.subplots(figsize=(7, 4), layout='constrained')
bottom = np.zeros(2)
for j, (label, color) in enumerate([('Near', '#bad9ef'), ('Far', '#eab571')]):
    bars = ax.bar(names, shares[:, j], bottom=bottom, label=label, color=color)
    ax.bar_label(bars, labels=[f'{v:g}%' for v in shares[:, j]], label_type='center')
    bottom += shares[:, j]
ax.set(ylim=(0, 100), ylabel='Distance mix within method (%)')
ax.legend()
plt.show()
print('공통 구성비 75%·25%: Fast 20%, Regular 10%')

UCBAdmissions · 공식 설명과 R 재현

R datasets 공식 문서는 1973년 Berkeley 6개 주요 학과 지원자 4,526명의 입학 여부·성별·학과별 집계라고 설명합니다. 남성 1,198/2,691=44.5%, 여성 557/1,835=30.4%입니다.

학과별 지원 구성의 차이를 함께 살피는 자료입니다. 실제 학과별 차이는 서로 다를 수 있으므로, 모든 학과에서 한 방향으로 역전된다고 가정하지 않습니다. 6개 학과 자료로 대학 전체나 다른 연도까지 확대하지 않습니다.

자가 실습 200건 · 답안

비교 범위빠른배송일반배송
전체28/100 = 28%42/100 = 42%
근거리16/80 = 20%2/20 = 10%
원거리12/20 = 60%40/80 = 50%
방식 내 근거리 비중80/100 = 80%20/100 = 20%
공통 구성 50%·50%0.5×20%+0.5×60%=40%0.5×10%+0.5×50%=30%

전체에서는 빠른배송이 낮지만 근거리·원거리에서는 각각 10%p 높습니다. 전체 비율은 각각 0.8×20%+0.2×60%=28%, 0.2×10%+0.8×50%=42%로 재현됩니다. 이 표본도 교육용 가상 자료이며, 지연 감소 효과를 확정하지 않습니다.

이해 점검 해설

  1. 계산: (70/80)×10%+(10/80)×50%=15%입니다. 근거리·원거리의 주문 수가 가중치가 됩니다.
  2. 해석: 0/5는 관찰한 다섯 주문에 대한 사실입니다. 더 많은 주문에서 지연이 발생할 가능성을 배제하지 않습니다.
  3. 검증: 거리 미분류 주문이 빠졌는지, 중복 주문이 있는지, 집계 대상과 범주 분류 규칙이 같은지 확인합니다. 전체 수와 층별 수가 다른 이유를 먼저 설명한 뒤 비율을 비교합니다.
