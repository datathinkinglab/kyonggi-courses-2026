2. 중심위치의 세 가지 측도

2.1 산술평균(Mean): 모두의 크기를 반영하는 균형점

Section 2.1
산술평균의 정의와 분모 규칙
\[ \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i = \frac{687}{20} = 34.35\text{분} \]
  • 유효 관측값 \(x_1, \ldots, x_n\)의 합계(\(687\)분)를 유효 관측 수 \(n=20\)으로 나눈 값입니다.
  • 주의: 전체 학생 \(22\)명을 분모로 쓰면(\(687/22 \approx 31.23\)), 미응답 2명을 사실상 0분 통학으로 취급하는 심각한 왜곡이 발생합니다.
평균이 가진 두 가지 구조적 성질 (판서 핵심)
성질 1 · 편차의 합은 항상 0이다 (무게중심 / 균형점)
\[ \sum_{i=1}^{n}(x_i - \bar{x}) = \sum_{i=1}^{n} x_i - n\bar{x} = 0 \]

작은 값들의 음(-)의 편차와 큰 값들의 양(+)의 편차가 정확히 상쇄됩니다. 수직선 위에 같은 무게의 추를 올려놓았을 때 수평을 이루는 시소의 받침점(균형점)입니다.

성질 2 · 제곱거리의 합을 최소화한다 (최소제곱 성질)
임의의 기준값 \(a\)에 대하여: \[ \sum_{i=1}^{n}(x_i - a)^2 = \sum_{i=1}^{n}\{(x_i - \bar{x}) + (\bar{x} - a)\}^2 = \sum_{i=1}^{n}(x_i - \bar{x})^2 + \underbrace{n(a - \bar{x})^2}_{\ge 0} \]

미분 없이도 마지막 항 \(n(a-\bar{x})^2 \ge 0\)이므로 \(a = \bar{x}\)일 때 제곱오차 합이 최소가 됨을 알 수 있습니다. 거리가 2배면 제곱거리는 4배가 되므로, 평균이 극단값에 민감한 것은 단순 계산 실수가 아니라 제곱거리를 줄이려는 평균의 구조적 본질입니다.

2. 중심위치의 세 가지 측도

2.2 중앙값(Median): 크기보다 정렬된 순서에 주목한다

Section 2.2
순서통계량(Order Statistics)과 중앙값 정의

오름차순 정렬한 값을 \(x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}\)으로 표기합니다.
※ 괄호 첨자 \((i)\)는 원래 학생 번호가 아니라 정렬 후 순서입니다!

\[ \operatorname{Med}(x) = \begin{cases} x_{((n+1)/2)}, & n\text{이 홀수} \\[6pt] \dfrac{x_{(n/2)} + x_{(n/2+1)}}{2}, & n\text{이 짝수} \end{cases} \]
통학 자료 (\(n=20\), 짝수) 계산:
10번째 값 \(x_{(10)}=30\)과 11번째 값 \(x_{(11)}=32\)의 평균:
\[ \operatorname{Med}(x) = \frac{30 + 32}{2} = 31\text{분} \] (실제 31분이라고 응답한 학생은 없지만 중앙값으로 사용 가능)
중앙값의 해석 주의점과 수리적 성질
주의 · 동점(Ties)이 있을 때의 절반 해석

중앙값 이하와 이상에는 각각 적어도 절반(\(50\%\))의 관측이 있습니다. 단, 동점이 많으면 “엄격히 작은 값과 큰 값이 정확히 절반씩”이라는 설명은 틀릴 수 있습니다.
반례: [1, 2, 2, 2, 9]에서 중앙값은 2이지만, 2보다 엄격히 작은 값은 1 한 개(20%)뿐입니다.

성질 · 절대거리의 합을 최소화한다 (최소절대편차)
\[ \min_{a} \sum_{i=1}^{n} |x_i - a| \implies a = \operatorname{Med}(x) \]

기준점 \(a\)를 오른쪽으로 \(\delta\)만큼 옮기면, 왼쪽 점들과의 거리는 \(\delta\)씩 늘어나고 오른쪽 점들과의 거리는 \(\delta\)씩 줄어듭니다. 따라서 양쪽 점의 개수가 같아지는 정중앙에서 절대거리 합이 최소가 됩니다. (짝수 표본에서는 가운데 두 값 사이의 모든 점이 최소값을 만들며 관례상 두 값의 평균을 보고)

2.3 최빈값(Mode)의 한계와 2.4 목적별 대표값 선택

Section 2.3 – 2.4
최빈값 ≠ 과반수

통학 자료에서 20분이 2회, 나머지는 1회씩 관측되므로 최빈값은 20분입니다.

그러나 비율은 \(2/20 = \mathbf{10\%}\)에 불과합니다. “가장 자주 나온 값”이 “대다수(과반수)가 선택한 값”을 뜻하지는 않습니다. 최고 빈도가 여러 개면 공동 최빈값을 모두 보고합니다.

측정 척도와 대표값

명목척도(교통수단): 최빈 범주 사용 가능. 단, 버스=1, 지하철=2, 도보=3 코드의 평균 1.8은 아무 의미가 없습니다.

순서척도(만족도 등급): 중앙 범주는 해석 가능하나, 등급 간격이 동일하다는 근거 없이 숫자 평균을 내는 것은 주의해야 합니다.

연속형 자료와 봉우리

연속형 자료는 측정 정밀도에 따라 정확히 같은 값이 아예 없을 수 있습니다.

원자료의 최빈값과 히스토그램의 최고 빈도 구간(Bin), 밀도곡선의 봉우리(Peak)는 서로 구별해야 합니다(구간 폭에 따라 달라짐).

분석 목적 (무엇을 요약하려는가?) 우선 살펴볼 대표값 반드시 함께 확인·보고할 항목

3. 저항성 (Resistance)

한 관측값의 변화가 결론을 얼마나 움직이는가?

Section 3.1 – 3.2
저항성(Resistance)의 정의: 일부 관측값의 급격한 변화(극단값·입력 오류 등)가 통계적 요약값에 지나치게 큰 영향을 주지 않는 성질입니다.
3.1 평균의 변화를 수식으로 예측하기

\(n=20\)명 중 한 학생의 값을 \(x_j\)에서 \(x_j + \Delta\)로 교체(인원 \(n=20\) 유지)하면 새로운 평균은 정확히 \(\Delta / n\)만큼 변합니다:

\[ \bar{x}_{\mathrm{new}} = \bar{x} + \frac{\Delta}{n} \]
  • 90분 → 190분 교체 (\(\Delta = +100\)):
    \(\bar{x}_{\mathrm{new}} = 34.35 + \frac{100}{20} = 34.35 + 5 = \mathbf{39.35\text{분}}\)
  • 90분 → 990분 교체 (\(\Delta = +900\)):
    \(\bar{x}_{\mathrm{new}} = 34.35 + \frac{900}{20} = 34.35 + 45 = \mathbf{79.35\text{분}}\)
  • 한 값만 한없이 키우면 평균도 한없이 끌려갑니다(비저항적).
3.2 중앙값은 왜 31분 그대로인가? (그리고 반례)

90분은 이미 정렬된 20개 중 가장 큰 값(\(x_{(20)}\))입니다. 이 값을 190이나 990으로 키워도 가운데 10번째(30분)·11번째(32분) 값의 순서와 크기는 전혀 바뀌지 않으므로 중앙값은 계속 31분입니다.

핵심 구별: ‘저항적(Resistant)’ ≠ ‘절대 불변(Invariant)’
중앙값이 어떤 변화에도 절대 안 변한다는 뜻이 아닙니다!
반례: [1, 2, 3, 4, 5] (중앙값 3)에서 가운데 값 3을 100으로 바꾸면 정렬 결과는 [1, 2, 4, 5, 100]이 되어 중앙값은 4로 변합니다.
→ “가운데 순서를 건드리지 않는 극단값 변화에 저항적이다”라고 정확히 이해해야 합니다.

3.3 저항성이 높으면 언제나 더 좋은가?

아닙니다! 전체 20명의 총 통학 시간을 구할 때는 \(\text{평균}\times 20 = 687\text{분}\)이 맞으며, \(\text{중앙값}\times 20 = 620\text{분}\)은 합계가 아닙니다.

또한 저항성은 표본 선택 편향(Selection Bias)이나 결측 문제를 해결해주지 않습니다. 짧은 통학 시간 학생만 응답했다면 중앙값도 전체 학생을 대표하지 못합니다.

3.4 분포 모양과 대표값의 기계적 암기 주의

오른쪽 꼬리가 긴 분포에서 흔히 \(\text{평균} > \text{중앙값}\)이지만, 이를 절대 법칙으로 외우지 마세요.
• \(\text{평균} = \text{중앙값}\)이라고 무조건 대칭/정규분포가 아닙니다.
• 대칭인 이봉분포(Bimodal)에서는 평균과 중앙값이 정중앙의 가장 드문 골짜기에 놓일 수도 있습니다. 반드시 4차수의 그래프와 함께 확인합니다!

4. 분위수와 사분위범위

4.1 왜 산포가 필요한가? & 4.2 표본 분위수의 선형 보간 규칙

Section 4.1 – 4.2
4.1 중심 하나로 분포를 설명할 수 없다: 자료 \(A=[28, 30, 32]\)와 \(B=[10, 30, 50]\)은 평균과 중앙값이 모두 \(30\)으로 같지만 퍼짐(산포)이 전혀 다릅니다. 4차수의 누적비율이 “어떤 값까지 얼마나 쌓였는가”를 물었다면, 분위수(Quantile)는 “주어진 비율 \(p\)에 대응하는 경계값은 어디인가”를 묻습니다.
우리 수업의 표준 규칙: 선형 보간 (NumPy method="linear")

유한 표본에서는 \(25\%\) 위치에 딱 떨어지는 관측점이 없을 수 있어 계산 규칙을 명시해야 합니다. 정렬된 순서를 \(1\)부터 \(n\)까지 셀 때 비율 \(p\)의 가상 위치 \(h\)는:

\[ h = 1 + (n - 1)p, \quad j = \lfloor h \rfloor \text{ (정수부)}, \quad g = h - j \text{ (소수부)} \] \[ Q(p) = (1 - g)\,x_{(j)} + g\,x_{(j+1)} = x_{(j)} + g\,\bigl(x_{(j+1)} - x_{(j)}\bigr) \]

※ \(p=0\)이면 최솟값 \(x_{(1)}\), \(p=1\)이면 최댓값 \(x_{(n)}\)입니다.

통학 자료 (\(n=20\)) 사분위수 단계별 계산
구분 위치 \(h = 1 + 19p\) 이웃한 두 관측값 선형 보간 결과
\(Q_1\) (\(p=0.25\)) \(1 + 19(0.25) = \mathbf{5.75}\) \(x_{(5)}=20,\; x_{(6)}=20\) \(20 + 0.75(0) = \mathbf{20\text{분}}\)
\(Q_2\) (\(p=0.50\)) \(1 + 19(0.50) = \mathbf{10.50}\) \(x_{(10)}=30,\; x_{(11)}=32\) \(30 + 0.50(2) = \mathbf{31\text{분}}\)
\(Q_3\) (\(p=0.75\)) \(1 + 19(0.75) = \mathbf{15.25}\) \(x_{(15)}=42,\; x_{(16)}=45\) \(42 + 0.25(3) = \mathbf{42.75\text{분}}\)
왜 어떤 교재는 \(Q_3 = 43.5\)분인가요?
‘위쪽 절반 10개(\(x_{(11)}\sim x_{(20)}\))의 중앙값’ 방식을 쓰면 \((x_{(15)}+x_{(16)})/2 = (42+45)/2 = 43.5\)분이 됩니다. 42.75와 43.5가 다르다고 한쪽을 오류라고 단정하지 말고, 어떤 정의(규칙)를 썼는지부터 확인해야 합니다.
4. 분위수와 사분위범위

4.3 사분위범위(\(IQR\))의 의미와 그림 5-3 · 두 축의 비교

Figure 5-3 & Section 4.3–4.4
\(IQR\) 정의와 저항성
\[ IQR = Q_3 - Q_1 = 42.75 - 20 = \mathbf{22.75\text{분}} \]

중간 50% 구간의 폭(단위: 분). 90→990분 교체 시 범위(Range)는 \(80\to 980\)분으로 폭증하지만, \(IQR\)은 \(22.75\)분으로 유지됩니다.

흔한 오해 2가지 주의

① \(Q_1, Q_3\)는 최솟값~최댓값 길이를 4등분한 점이 아닙니다(정렬된 순서 비율 위치).
② 유한 표본·동점·보간 때문에 닫힌 구간 \([Q_1, Q_3]\) 안의 점 개수가 항상 정확히 50%인 것은 아닙니다.

4.4 분산 · 표준편차와 비교

표본분산 \(s^2 = \frac{\sum(x_i-\bar{x})^2}{n-1}\) (단위: 분²), 표준편차 \(s=\sqrt{s^2}\) (단위: 분).
평균으로부터의 제곱거리를 쓰므로 극단값에 민감합니다. 반면 \(IQR\)은 가운데 구간의 퍼짐에 집중합니다.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

raw = pd.Series([10,12,15,18,20,20,22,25,28,30,
                 32,35,38,40,42,45,50,55,60,90,None,None],
                name="minutes", dtype="float64")
x = raw.dropna().to_numpy()
assert len(x) > 0 and np.isfinite(x).all() and (x >= 0).all()

[Colab 셀 2 코드 작성 요청] 앞선 셀 1의 유효 데이터 배열 `x`를 이어받아 값 교체 실험 코드를 작성해줘: 1. 원본 `x`가 훼손되지 않도록 반복문에서 `changed = x.copy()`로 복사본을 만들어줘. 2. 마지막 값(원래 90분)을 `[90, 190, 990]`으로 각각 교체(`changed[-1] = replacement`)해줘. 3. 각 교체값마다 평균(mean), 중앙값(median), IQR(method="linear" 기준)을 계산해 DataFrame `result`로 출력해줘. 4. 새로운 평균이 수식 `34.35 + (replacement - 90) / 20`과 일치하는지, 그리고 원본 `x[-1]`이 여전히 90이고 중앙값(31)과 IQR(22.75)이 유지되는지 `assert`로 검증해줘. 5. 가로축을 교체값(replacement), 세로축을 대표값(Location)으로 하여 Mean("o-")과 Median("s-")의 변화를 비교하는 꺾은선 그래프를 그려줘.
비교·검증용 표준 Python 코드 (셀 2) 
rows = []
for replacement in [90, 190, 990]:
    changed = x.copy()
    changed[-1] = replacement  # 이 자료의 마지막 유효값은 90
    qs = np.quantile(changed, [0.25, 0.5, 0.75], method="linear")
    rows.append({"replacement": replacement, "mean": changed.mean(),
                 "median": qs[1], "IQR": qs[2]-qs[0]})
    expected_mean = 34.35 + (replacement-90)/20
    assert np.isclose(changed.mean(), expected_mean)
result = pd.DataFrame(rows)
print(result.to_string(index=False))
assert x[-1] == 90 and raw.iloc[19] == 90
assert np.allclose(result["median"], 31)
assert np.allclose(result["IQR"], 22.75)

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(result["replacement"], result["mean"], "o-", label="Mean")
ax.plot(result["replacement"], result["median"], "s-", label="Median")
ax.set(xlabel="Replacement of the original 90 (minutes)",
       ylabel="Location (minutes)", title="One value replaced; valid n=20")
ax.legend()
fig.tight_layout()
plt.show()

왜 x.copy()를 반드시 써야 할까?

파이썬에서 그냥 changed = x라고 쓰면 같은 메모리를 가리켜 원본 x까지 바뀝니다. x.copy()로 독립된 복사본을 만들어야 원자료가 안전하게 보존됩니다.

“교육용 가상 응답 22건 중 통학 시간 유효값은 20건이며 2건은 결측이다. 유효 응답의 평균은 34.35분, 중앙값은 31분이다. 가운데 통학 시간을 설명할 때는 중앙값을, 유효 응답의 시간 합계 687분과 연결할 때는 평균을 사용한다. 선형 보간 기준 \(Q_1=20\)분, \(Q_3=42.75\)분, \(IQR=22.75\)분이다. 90분을 더 크게 바꾸는 실험에서 평균은 증가하고 중앙값은 유지되었다. 이 가상 자료의 결과를 실제 전체 학생에게 일반화하지 않는다.”

각 질문을 먼저 생각해보고 버튼을 눌러 정답과 핵심 조건을 확인하세요.

Q1. 유효 응답 20명 중 한 값이 200분 증가하면 평균은 얼마나 변하는가?
→ \(\Delta/n = 200/20 = \mathbf{+10\text{분 증가}}\) (단, 인원 \(n=20\) 고정이 조건!)
Q2. 중앙값이 31분이면 반드시 통학 시간이 31분인 응답자가 존재하는가?
→ 아니다! 짝수 표본에서 가운데 두 값(30분, 32분)의 평균일 수 있다.
Q3. \(Q_3\)가 교재(43.5분)와 코드(42.75분)에서 다르면 무엇부터 확인하는가?
→ 같은 자료 · 결측 처리 · 분위수 보간 정의(규칙)를 사용했는지부터 확인한다.
Q4. 사분위범위 \(IQR = 0\)이면 자료의 모든 관측값이 서로 같은가?
→ 아니다! 반례: [0, 0, 0, 0, 100]은 \(Q_1=Q_3=0\)이라 \(IQR=0\)이지만 100이 존재한다.
Q5. 평균과 중앙값 중 어떤 상황에서도 항상 더 우월한 대표값이 있는가?
→ 없다! 요약하려는 목적(총합 연계 vs 가운데 순서)과 분포 특성을 함께 봐야 한다.
다음 6차수 예고: 오늘 계산한 \(Q_1 \cdot \text{중앙값} \cdot Q_3\)에 최솟값·최댓값을 더해 5수요약(Five-number summary)을 만들고 상자그림(Boxplot)으로 시각화합니다. \(IQR\)을 이용한 이상점(Outlier) 경계는 ‘자동 삭제 규칙’이 아니라 ‘우선 조사할 관측값을 찾는 탐색 규칙’으로 배웁니다.
5차수 심화 학습 · 다양한 평균의 확장

집단 평균의 함정(가중평균)과 절사평균(Trimmed Mean)

Advanced Topic 5-A & 5-B
심화 5-A · 집단 평균을 다시 단순 평균내면 생기는 문제

• A집단 (2명): 평균 통학 시간 \(10\)분 (합계 \(20\)분)
• B집단 (8명): 평균 통학 시간 \(40\)분 (합계 \(320\)분)

단순 평균의 오류: \(\dfrac{10 + 40}{2} = 25\text{분}\) (X)
→ 2명인 소집단과 8명인 대집단에 똑같은 50:50 비중을 부여하는 오류!
\[ \text{전체 평균 (가중평균)} = \frac{2\times 10 + 8\times 40}{2 + 8} = \frac{340}{10} = \mathbf{34\text{분}} \]

전체 학생이 관측 단위라면 반드시 각 집단의 유효 응답 수(\(n_k\))를 가중치로 곱해 합산해야 합니다.

심화 5-B · 절사평균(Trimmed Mean)은 중앙값과 어떻게 다른가?

앞서 다룬 8개 손계산 자료 [10, 20, 20, 30, 40, 50, 60, 90]에서 양끝 최솟값(10)과 최댓값(90)을 한 개씩(각 꼬리 \(1/8 = 12.5\%\)) 제외하고 평균을 내면:

\[ \text{남은 자료: } [20, 20, 30, 40, 50, 60] \] \[ \bar{x}_{\text{trim}(12.5\%)} = \frac{220}{6} \approx \mathbf{36.67\text{분}} \]
  • 양끝 극단값의 영향을 줄이면서 내부 값들의 크기도 반영하는 평균(40분)과 중앙값(35분)의 절충적 요약입니다(예: 체조·다이빙 판정).
  • 주의: 원자료에서 10과 90을 영구 삭제하라는 뜻이 아닙니다! (절사 비율, 제외 개수, 원래 평균을 함께 보고)
  • 토론 질문: “8명의 총 통학 시간을 구할 때 \(\text{절사평균}(36.67)\times 8\)을 써도 되는가?” → 아니다! 총합은 원래 평균 \(\times 8 = 320\)분만 성립합니다.

5. 손계산 활동 (\(n=8\)) 정답 표 및 단계별 해설

원자료 (\(n=8\)): 10, 20, 20, 30, 40, 50, 60, 90 (단위: 분, 결측 없음)
문제 항목 단계별 손계산 과정 (검증 기준) 정답
1. 합계 및 산술평균 합계 \(= 10+20+20+30+40+50+60+90 = 320\),   평균 \(= 320 / 8\) 합계 320분 / 평균 40분
1. 중앙값 및 최빈값 짝수(\(n=8\))이므로 \((x_{(4)}+x_{(5)})/2 = (30+40)/2\),   20분이 유일하게 2회 출현 중앙값 35분 / 최빈값 20분
2. 제1사분위수 (\(Q_1\)) \(h = 1 + 7(0.25) = \mathbf{2.75} \implies x_{(2)} + 0.75(x_{(3)} - x_{(2)}) = 20 + 0.75(20 - 20)\) 20분
2. 제3사분위수 (\(Q_3\)) \(h = 1 + 7(0.75) = \mathbf{6.25} \implies x_{(6)} + 0.25(x_{(7)} - x_{(6)}) = 50 + 0.25(60 - 50)\) 52.5분
2. 사분위범위 (\(IQR\)) \(IQR = Q_3 - Q_1 = 52.5 - 20\) 32.5분
3. 90→190 교체 후 평균 관측 추가가 아닌 ‘교체’이므로 분모 \(n=8\) 유지: \(\bar{x}_{\text{new}} = 40 + \frac{100}{8} = 40 + 12.5\) 52.5분 (+12.5분 증가)
3. 90→190 교체 후 중앙값 가운데 두 값 \(x_{(4)}=30, x_{(5)}=40\)의 순서가 그대로 유지됨 35분 (변화 없음)
문제 4 해설 (‘최빈값 20분이므로 대부분이 20분 걸린다’의 문제점):
20분 응답자는 8명 중 2명으로 전체의 \(2/8 = 25\%\)에 불과합니다. 나머지 75%(6명)는 20분이 아니므로 “학생 대부분(과반수)이 20분 걸린다”는 주장은 최빈값과 과반수를 혼동한 잘못된 해석입니다.

rows = []
for replacement in [90, 190, 990]:
    changed = x.copy()          # 원자료 훼손 방지를 위해 반드시 복사본 생성
    changed[-1] = replacement   # 마지막 유효값(90분)을 교체
    qs = np.quantile(changed, [0.25, 0.5, 0.75], method="linear")

                 "median": qs[1], "IQR": qs[2]-qs[0]})
    expected_mean = 34.35 + (replacement-90)/20
    assert np.isclose(changed.mean(), expected_mean)

result = pd.DataFrame(rows)

before = np.array([1, 2, 3, 4, 5])
after = np.array([1, 2, 100, 4, 5])
print("정렬 전후:", np.sort(before), np.sort(after))
print("중앙값 전후:", np.median(before), np.median(after))

핵심 포인트: 가운데 값 3이 100으로 바뀌면 정렬 순서가 [1, 2, 4, 5, 100]으로 재편되어 중앙값이 3에서 4로 이동합니다. 즉, 중앙값은 극단값 변화에 저항적(resistant)이지만 어떤 변화에도 안 변하는 불변(invariant)은 아닙니다.

가정용 자가 실습 (도서관 이용 시간) 상세 정답 및 해설

과제 문항 단계별 풀이 및 수식 정답
1. 인원 및 합계/평균 전체 \(N=18\), 유효 \(n=16\), 결측 \(2\). 합계 \(= 166\text{시간}\), 평균 \(= 166 / 16\) 합계 166시간 / 평균 10.375시간
1. 중앙값 및 최빈값 \(n=16\)(짝수)이므로 \((x_{(8)}+x_{(9)})/2 = (7+8)/2\), 4시간이 3회 출현(비율 \(3/16=18.75\%\)) 중앙값 7.5시간 / 최빈값 4시간
