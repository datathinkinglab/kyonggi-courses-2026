관측한 분포와 확률모형

경험분포는 관측된 값들의 비율을 요약한다. 확률모형은 가능한 값과 확률을 정해 아직 관측하지 않은 결과도 생각할 수 있게 한다.

확률변수는 실험 결과에 수치를 대응시킨다. 동전을 두 번 던져 HH가 나오면 앞면 횟수 X는 2다. 측정값을 연속형으로 모형화하면 확률은 구간으로 계산한다.

관측에서 출발

관측 예시가 0, 0, 1, 2이면 0의 경험적 비율은 2/4다.

모형에서 출발

공정한 동전 두 번에서 앞면이 0번 나올 모형 확률은 1/4이다.

누적확률과 분위수는 방향이 반대다

F(x) = P(X ≤ x). CDF는 값 x를 누적확률로, 정규분포의 분위수 함수는 확률 p를 값으로 보낸다. 예를 들어 F(1) ≈ 0.8413이다.

값 → 확률

표준정규에서 z=0이면 F(0)=0.5다.

확률 → 값

같은 분포에서 p=0.5인 분위수는 0이다.

정규분포에서 μ와 σ가 정하는 것

정규분포에서 평균 μ는 중심을 옮기고 표준편차 σ는 폭을 바꾼다. 모집단의 X가 정규분포를 따를 때 (X−μ)/σ는 표준정규분포 N(0, 1)를 따른다.

ppf(p)누적확률 p에 해당하는 값은?
rvs(...)이 모형에서 난수를 생성하면?

점선은 표준정규 N(0, 1), 실선은 비교할 정규분포다. 두 패널의 축 눈금은 같다.

순위에서 Q–Q 플롯의 점 하나 만들기

  1. 관측값을 작은 순서대로 정렬해 x₍ᵢ₎를 구한다.
  2. 순위 i에 중간순위 확률 pᵢ = (i − 0.5)/n을 배정한다.
  3. 표준정규 분위수 zᵢ = Φ⁻¹(pᵢ)를 찾는다.
  4. 가로 zᵢ, 세로 x₍ᵢ₎를 한 점으로 그린다.
pᵢ는 그림의 확률 배치 규칙이다. n=3에서 가운데 점의 p는 0.5다. 이때 가로 좌표는 어디에 놓일까?
정렬

[14, 8, 10] → [8, 10, 14]

확률 배치

n=3에서 i=2이면 p=(2−0.5)/3=0.5

점으로 옮기기

가운데 관측값의 좌표는 (0, 10)

확률 배치는 양 끝에서 0과 1을 피한다. 같은 표본에서 확률 규칙을 바꾸어도 정렬된 관측값은 그대로다.

좌표가 다르면 확률 배치부터 확인하기

수업의 중간순위 방식과 SciPy의 Filliben 방식은 순위에 붙이는 확률이 다르다. 같은 자료라면 두 방식의 세로 좌표는 같고 가로 좌표는 달라질 수 있다.

Filliben은 양 끝에 1−0.5^(1/n), 0.5^(1/n)을 놓고 내부 순위에는 (i−0.3175)/(n+0.365)를 쓴다.

검증 기준 · 같은 배치 규칙으로 계산했을 때 두 좌표 배열이 허용오차 안에서 일치하는가?

파란 점은 중간순위, 주황색 원은 Filliben이다. i/n을 쓰면 마지막 p=1에서 표준정규 분위수가 유한하지 않다.

프롬프트 · 가상 소득의 변환 전후 비교

8차수 가상 소득을 다시 사용한다. 원자료와 Z점수에서 가장 오른쪽 점의 이탈 방향을 먼저 예상한다.

교육용 가상 자료 [120,140,150,160,170,180,190,200,210,220,230,240,250,270,300,350,400,500,700,1200,None,None]에서 전체·유효·결측 건수를 확인해줘.
같은 유효 관측으로 원자료(만 원), Z점수(ddof=1), 최대우도 Box–Cox 변환의 정규 분위수 대조도를 나란히 그려줘. Filliben 확률과 표준정규 분위수, 각 패널의 최소제곱 기준선을 사용해줘.
원자료와 Z점수의 표준화 잔차가 일치하는지 검증하고, Box–Cox 전후 양 끝점의 표준화 잔차를 표로 보여줘. 표준화 잔차는 (관측값−기준선 값)/해당 척도의 표본표준편차로 정의해줘. 해석은 내가 작성할 수 있도록 질문만 남겨줘.
입력 확인

전체·유효·결측 건수를 적고 같은 관측을 세 패널에 사용한다.

경계 사례

유효값이 2개 미만이거나 상수인 자료는 비교를 중단한다. Box–Cox에는 양수가 필요하다.

결과 확인

두 꼬리를 같은 척도로 비교할 때는 잔차를 해당 척도의 표본표준편차로 나눈다.

비교용 Python · 두 좌표 배치

관측값 [14, 8, 10]을 정렬하고, 순위 i마다 p=(i−0.5)/n과 표준정규 분위수 z를 구해 표를 만들어줘. 가로축은 z, 세로축은 정렬 관측값으로 점을 그려줘.
같은 자료에서 Filliben 방식의 확률도 직접 계산해 SciPy probplot(fit=False)과 좌표를 대조해줘. 중간순위 방식의 가로 좌표가 왜 다른지도 설명해줘.
from statistics import NormalDist
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

normal = NormalDist()

def qq_coordinates(values, method):
    ordered = np.sort(np.asarray(values, dtype=float))
    n = len(ordered)
    if n < 2 or not np.isfinite(ordered).all():
        raise ValueError("Need at least two finite values.")
    i = np.arange(1, n + 1)
    if method == "midrank":
        p = (i - 0.5) / n
    elif method == "filliben":
        p = (i - 0.3175) / (n + 0.365)
        p[-1] = 0.5 ** (1 / n)
        p[0] = 1 - p[-1]
    else:
        raise ValueError("Unknown plotting position.")
    q = np.array([normal.inv_cdf(value) for value in p])
    return q, ordered, p

x = [14, 8, 10]
q_mid, y, p_mid = qq_coordinates(x, "midrank")
q_fill, y_fill, _ = qq_coordinates(x, "filliben")
q_scipy, y_scipy = stats.probplot(x, dist="norm", fit=False)
np.testing.assert_array_equal(y, [8, 10, 14])
np.testing.assert_array_equal(y_fill, y_scipy)
np.testing.assert_allclose(q_fill, q_scipy, atol=1e-12)
assert not np.allclose(q_mid, q_scipy)
for p, q, value in zip(p_mid, q_mid, y):
    print(f"p={p:.4f}, z={q:.4f}, x={value:g}")

plt.scatter(q_mid, y, marker="x", label="Midrank (manual)")
plt.scatter(q_scipy, y_scipy, facecolors="none", edgecolors="C1",
            label="Filliben (SciPy)")
plt.xlabel("Theoretical standard normal quantile")
plt.ylabel("Ordered observations")
plt.legend()
plt.show()

손계산 · 표준화 전후의 이탈

22건에서 결측 2건을 빼면 20건이다. Filliben의 마지막 p는 0.5^(1/20) ≈ 0.96594이고, 표준정규 분위수는 약 1.82416이다. 마지막 관측값은 1200만 원이다.

원자료의 기준선 예측값을 ŷ, 평균을 x̄, 표본표준편차를 s라고 하자. 관측값과 기준선에 같은 Z변환을 적용하면 [(x−x̄)/s] − [(ŷ−x̄)/s] = (x−ŷ)/s다.

가장 큰 관측값의 표준화 잔차는 원자료와 Z점수에서 모두 약 +2.0106이다. Box–Cox 이후에는 약 +0.0266이다.

비교용 Python · 가상 소득 변환

교육용 가상 자료 [120,140,150,160,170,180,190,200,210,220,230,240,250,270,300,350,400,500,700,1200,None,None]에서 전체·유효·결측 건수를 확인해줘.
같은 유효 관측으로 원자료(만 원), Z점수(ddof=1), 최대우도 Box–Cox 변환의 정규 분위수 대조도를 나란히 그려줘. Filliben 확률과 표준정규 분위수, 각 패널의 최소제곱 기준선을 사용해줘.
원자료와 Z점수의 표준화 잔차가 일치하는지 검증하고, Box–Cox 전후 양 끝점의 표준화 잔차를 표로 보여줘. 표준화 잔차는 (관측값−기준선 값)/해당 척도의 표본표준편차로 정의해줘. 해석은 내가 작성할 수 있도록 질문만 남겨줘.
from statistics import NormalDist
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

normal = NormalDist()

def qq_coordinates(values, method):
    ordered = np.sort(np.asarray(values, dtype=float))
    n = len(ordered)
    if n < 2 or not np.isfinite(ordered).all():
        raise ValueError("Need at least two finite values.")
    i = np.arange(1, n + 1)
    if method == "midrank":
        p = (i - 0.5) / n
    elif method == "filliben":
        p = (i - 0.3175) / (n + 0.365)
        p[-1] = 0.5 ** (1 / n)
        p[0] = 1 - p[-1]
    else:
        raise ValueError("Unknown plotting position.")
    q = np.array([normal.inv_cdf(value) for value in p])
    return q, ordered, p

raw = [120,140,150,160,170,180,190,200,210,220,230,240,250,270,300,350,400,500,700,1200,None,None]
x = np.array([value for value in raw if value is not None], dtype=float)
print("Total, valid, missing:", len(raw), len(x), raw.count(None))
if len(x) < 2 or not np.isfinite(x).all() or np.ptp(x) == 0:
    raise ValueError("Need at least two finite, nonconstant observations.")
if np.any(x <= 0):
    raise ValueError("Box-Cox requires positive observations.")

q, ordered, _ = qq_coordinates(x, "filliben")
q_scipy, y_scipy = stats.probplot(x, dist="norm", fit=False)
np.testing.assert_allclose(q, q_scipy, atol=1e-12)
np.testing.assert_array_equal(ordered, y_scipy)

z = (x - x.mean()) / x.std(ddof=1)
transformed, lam = stats.boxcox(x)
print(f"Box-Cox lambda={lam:.4f}")
panels = [
    ("Original", "10,000 KRW", x),
    ("Z-score", "Z-score", z),
    ("Box-Cox", "Transformed value", transformed),
]
fig, axes = plt.subplots(1, 3, figsize=(12, 3.8), sharex=True,
                         constrained_layout=True)
residuals = []
for ax, (label, unit, values) in zip(axes, panels):
    y = np.sort(values)
    slope, intercept = np.polyfit(q, y, 1)
    fitted = slope * q + intercept
    residual = (y - fitted) / y.std(ddof=1)
    residuals.append(residual)
    print(f"{label}: first={residual[0]:+.4f}, last={residual[-1]:+.4f}")
    ax.scatter(q, y, s=22)
    ax.plot(q, fitted, "--", color="tab:red")
    ax.set(title=f"{label} (n={len(y)})", xlabel="Theoretical N(0,1) quantile",
           ylabel=unit)
np.testing.assert_allclose(residuals[0], residuals[1], atol=1e-12)
plt.show()
