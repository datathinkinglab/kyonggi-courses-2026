3.2 왜 5수요약의 최댓값(90분)과 수염 끝(60분)이 다른가?

상자그림에는 최솟값~최댓값까지 무조건 수염을 잇는 방식도 있지만, 우리 수업에서는 \(1.5\times IQR\) 안쪽 울타리를 사용하고 울타리 밖 관측을 별도 점으로 표시하는 표준 상자그림(Tukey Boxplot)을 사용합니다.

핵심 구별: 이 자료의 최댓값은 90분이지만 위쪽 수염 끝은 60분입니다. 수염 끝을 최댓값이라고 읽으면 90분이라는 실제 관측을 놓치게 됩니다! 따라서 5수요약 표와 수염 끝 표는 서로 다른 정보를 기록합니다.

4. 울타리와 이상점

4.1 안쪽 울타리 · 4.2 수염 끝 집합 · 4.3 바깥쪽 울타리의 수식

Section 4.1 – 4.3
4.1 안쪽 울타리 (Inner Fences, \(1.5\,IQR\))
\[ L_{\mathrm{inner}} = Q_1 - 1.5\,IQR = 20 - 1.5(22.75) = \mathbf{-14.125\text{분}} \] \[ U_{\mathrm{inner}} = Q_3 + 1.5\,IQR = 42.75 + 1.5(22.75) = \mathbf{76.875\text{분}} \]
  • 경계 포함 규칙: 경계와 같은 값(\(x = L_{\mathrm{inner}}\) 또는 \(x = U_{\mathrm{inner}}\))은 울타리 내부로 포함하고, 엄격히 벗어난 값(\(x < L_{\mathrm{inner}}\) 또는 \(x > U_{\mathrm{inner}}\))만 이상점 후보로 표시합니다.
  • 음수 울타리 해석: \(L_{\mathrm{inner}} = -14.125\)분이라고 해서 음수 통학 시간이 존재한다는 뜻이 아닙니다. 공식에 따른 계산 경계이므로 임의로 0으로 고쳐 보고하지 않습니다.
4.2 수염 끝의 집합 정의 & 4.3 바깥쪽 울타리 (\(3\,IQR\))

울타리 내부 관측 집합 \(A = \{x_i : L_{\mathrm{inner}} \le x_i \le U_{\mathrm{inner}}\}\)에 대해:

\[ \text{아래 수염 끝} = \min(A) = \mathbf{10\text{분}}, \quad \text{위 수염 끝} = \max(A) = \mathbf{60\text{분}} \]

더 극단적인 관측을 구분하기 위한 바깥쪽 울타리(Outer Fences):

\[ L_{\mathrm{outer}} = Q_1 - 3\,IQR = \mathbf{-48.25\text{분}}, \quad U_{\mathrm{outer}} = Q_3 + 3\,IQR = \mathbf{111.0\text{분}} \]
구간 범위 조건 우리 수업에서의 공식 표현 통학 자료(\(n=20\)) 해당 관측값
\(L_{\mathrm{inner}} \le x_i \le U_{\mathrm{inner}}\) (\(-14.125 \sim 76.875\)) IQR 규칙으로 표시되지 않음 (수염 내부·경계) \(10\text{분} \sim 60\text{분}\) 사이의 19건
안쪽 울타리 밖 & 바깥쪽 울타리 내부·경계 안쪽 울타리 밖 이상점 후보 (Flagged) 90분 (1건) (\(76.875 < 90 \le 111\))
\(x_i < L_{\mathrm{outer}}\) 또는 \(x_i > U_{\mathrm{outer}}\) (\(111\text{분 초과}\)) 더 극단적인 이상점 후보 (Outer Flagged) 없음 (0건)

그림 6-2 · 이상점 후보 탐색과 처리 결정의 3단계 분리 흐름도 (표시 즉시 휴지통 삭제 금지!)
4.4 왜 1.5배 규칙을 맹신하면 안 되는가?

\(1.5\times IQR\)은 멀리 떨어진 관측을 눈여겨보기 위한 탐색적 관례(Rule of Thumb)일 뿐, 가설검정 유의수준이나 오류 증명 공식이 아닙니다.

오른쪽 꼬리가 긴 실제 분포(소득·통학시간·체류시간 등)에서는 정상적인 관측값 여러 개가 울타리 밖에 표시될 수 있습니다. 반대로 울타리 안에 있다고 해서 단위 오류가 전혀 없다는 보장도 없습니다.

4.5 예외 상황: \(IQR = 0\)인 자료의 처리

5차수 종료 질문에서 본 [0, 0, 0, 0, 100]은 \(Q_1 = Q_3 = 0\)이므로 \(IQR = 0\)이고, 안쪽 울타리도 \([0, 0]\)입니다.

• 수염은 \(0\)에서 끝나고 100은 별도 점으로 표시됩니다.
• \(IQR=0\)은 “전체 변동이 0”이라는 뜻이 아니라 “중간 구간에 동일한 값이 몰려 있다”는 뜻입니다. IQR=0을 숨기거나 임의의 작은 양수로 바꾸지 않고 빈도표·점그림과 함께 읽습니다.

비교·검증용 표준 Python 코드 (셀 1) 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def summarize_box(values, label):
    s = pd.Series(values, dtype="float64")
    x = s.dropna().to_numpy()
    if len(x) == 0:
        raise ValueError("유효 관측값이 없어 상자그림을 만들 수 없습니다.")
    if not np.isfinite(x).all() or (x < 0).any():
        raise ValueError("시간의 유한성·비음수 조건을 확인하세요.")
    q1, med, q3 = np.quantile(x, [0.25, 0.5, 0.75], method="linear")
    iqr = q3-q1
    lo, hi = q1-1.5*iqr, q3+1.5*iqr
    outer_lo, outer_hi = q1-3*iqr, q3+3*iqr
    inside = x[(x >= lo) & (x <= hi)]
    fliers = x[(x < lo) | (x > hi)]
    extreme = x[(x < outer_lo) | (x > outer_hi)]
    stats = {"label": label, "q1": q1, "med": med, "q3": q3,
             "whislo": inside.min(), "whishi": inside.max(),
             "fliers": fliers.tolist()}
    row = {"group": label, "total": len(s), "valid": len(x),
           "missing": int(s.isna().sum()), "min": x.min(),
           "Q1": q1, "median": med, "Q3": q3, "max": x.max(),
           "IQR": iqr, "inner_low": lo, "inner_high": hi,
           "outer_low": outer_lo, "outer_high": outer_hi,
           "whisker_low": inside.min(), "whisker_high": inside.max(),
           "flagged": fliers.tolist(), "outer_flagged": extreme.tolist()}
    return x, stats, row

raw = [10,12,15,18,20,20,22,25,28,30,
       32,35,38,40,42,45,50,55,60,90,None,None]
x, stats, row = summarize_box(raw, "Commute")
print(pd.Series(row))
assert (row["total"], row["valid"], row["missing"]) == (22,20,2)
assert np.allclose([row[k] for k in ["min","Q1","median","Q3","max"]],
                   [10,20,31,42.75,90])
assert np.allclose([row["inner_low"], row["inner_high"]], [-14.125,76.875])
assert np.allclose([row["outer_low"], row["outer_high"]], [-48.25,111])
assert stats["whislo"] == 10 and stats["whishi"] == 60
assert row["flagged"] == [90.0] and row["outer_flagged"] == []

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def summarize_box(values, label):
    s = pd.Series(values, dtype="float64")
    x = s.dropna().to_numpy()
    if len(x) == 0:
        raise ValueError("유효 관측값이 없어 상자그림을 만들 수 없습니다.")
    if not np.isfinite(x).all() or (x < 0).any():
        raise ValueError("시간의 유한성·비음수 조건을 확인하세요.")
    q1, med, q3 = np.quantile(x, [0.25, 0.5, 0.75], method="linear")
    iqr = q3-q1
    lo, hi = q1-1.5*iqr, q3+1.5*iqr
    outer_lo, outer_hi = q1-3*iqr, q3+3*iqr
    inside = x[(x >= lo) & (x <= hi)]
    fliers = x[(x < lo) | (x > hi)]
    extreme = x[(x < outer_lo) | (x > outer_hi)]
    stats = {"label": label, "q1": q1, "med": med, "q3": q3,
             "whislo": inside.min(), "whishi": inside.max(),
             "fliers": fliers.tolist()}
    row = {"group": label, "total": len(s), "valid": len(x),
           "missing": int(s.isna().sum()), "min": x.min(),
           "Q1": q1, "median": med, "Q3": q3, "max": x.max(),
           "IQR": iqr, "inner_low": lo, "inner_high": hi,
           "outer_low": outer_lo, "outer_high": outer_hi,
           "whisker_low": inside.min(), "whisker_high": inside.max(),
           "flagged": fliers.tolist(), "outer_flagged": extreme.tolist()}
    return x, stats, row
