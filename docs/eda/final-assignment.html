수행 과제

1. 공개 자료를 고르고 탐색 질문을 정하세요

공공데이터포털, 국가데이터처, Kaggle 등에서 실제 공개 자료를 고르세요. 출처 링크, 수집 시점과 맥락, 한 행의 의미, 주요 변수의 단위와 결측 처리 원칙을 기록하세요. 자료로 답할 수 있는 탐색 질문을 3개 이상 정하고 각 질문을 고른 이유를 적으세요.

2. 분포를 살피고 재표현을 적용하세요

질문에 맞는 수치요약과 그림을 선택하세요. 재표현을 1회 이상 적용하고 변환 전후 확률플롯을 비교해 변환을 선택한 근거를 설명하세요. 로그 변환을 검토한다면 0 이하의 값이 있는지 먼저 확인하고 처리 기준을 밝히세요.

3. 두 변수의 관계를 살피고 혼재변수를 검토하세요

이원 자료 분석을 1회 이상 수행하세요. 관계를 바꿔 보이게 할 수 있는 변수를 검토하고 층화가 가능하면 전체와 하위 집단의 결과를 비교하세요. 비율의 분모와 집단별 관측 수를 적고 관찰한 관계와 원인에 대한 해석을 구분하세요.

4. 주요 결과 3건을 독립적으로 확인하세요

손계산 대조, 다른 계산 경로로 교차확인, 결측·경계값 등 시험 입력을 활용하세요. 각 결과에 대해 예상값, 확인 절차, 실제 결과, 불일치와 수정 내용을 검증 로그에 남기세요. AI를 분석에 사용하고 주요 프롬프트, 응답과 수정 이유를 부록에 포함하세요.

5. 질문별 결론을 쓰고 분석을 재현하세요

질문마다 결론과 이를 뒷받침하는 표·그림을 연결하고 자료와 해석의 한계를 밝히세요. 팀원이 새 Colab 세션에서 첫 셀부터 실행해 핵심 결과를 다시 얻을 수 있도록 자료 접근 방법과 실행 순서를 기록하세요.

제출 및 발표 안내

구분안내
제출물재현 가능한 분석 노트북(.ipynb), 주요 결과 3건의 검증 로그, 주요 AI 대화 로그 부록
제출 방식팀별 노트북을 GitHub에 공개합니다. 제출 마감과 저장소 링크 전달 방법은 추후 안내합니다.
14차수프로젝트 클리닉에서 진행 상황을 공유하고 분석 방향과 검증 로그를 점검합니다.
15차수최종 발표에서 질문, 자료, 핵심 결과, 검증 근거와 한계를 설명합니다. 질의응답에서 검증 방법을 팀이 직접 설명합니다.

성적 반영 변경 안내

전체 성적은 중간고사 개인 과제 40%와 기말 팀 프로젝트 60%로 산정합니다.

기말 팀 프로젝트는 팀 공통 산출물 28%, 개인별 동료평가 12%, 최종 발표 20%를 전체 성적에 반영합니다. 산출물 100점은 팀 공통 70점과 개인별 동료평가 30점으로 구성하며, 산출물 점수는 전체 성적의 40%에 반영합니다.

평가 항목배점평가 기준
질문 설계15점탐색할 가치가 있고 자료로 답할 수 있는 질문을 정했다.
방법의 적절성15점요약, 시각화와 재표현이 자료의 특성과 질문에 맞는다.
검증의 엄밀성18점독립적인 방법으로 주요 결과를 확인하고 그 근거를 남겼다.
해석과 결론15점자료가 뒷받침하는 범위에서 질문에 답했다.
재현성과 소통7점다른 사람이 노트북을 재실행할 수 있고 문서에서 분석 판단의 근거를 이해할 수 있다.
동료평가30점각 팀원의 역할 수행, 분석과 검증 기여, 협업을 개인별로 평가한다.
합계100점산출물 점수로 전체 성적의 40%에 반영합니다.

검증 없이 AI 출력을 결론에 인용한 경우, 노트북이 처음부터 끝까지 실행되지 않는 경우, 심슨의 역설 위험이 있는 집계를 층화 검토 없이 사용한 경우에는 각각 10점을 감점합니다.

동료평가(Peer Review) · 개인별 30점

팀원 각자가 본인을 제외한 모든 팀원을 개별 평가합니다. 최종 발표 후 교수자에게 개별 제출하며, 응답은 팀원에게 공개하지 않습니다. 제출 기한과 제출처는 추후 안내합니다.

항목확인할 행동
역할 수행맡은 일을 일정에 맞춰 마치고 팀이 사용할 수 있는 결과를 공유했다.
분석과 검증 기여질문 설계, 자료 정리, 분석, 결과 검증 또는 결과 설명에 구체적으로 기여했다.
협업과 피드백진행 상황을 공유하고 팀원의 의견이나 수정 요청에 대응했다.

항목별로 0점(기여 없음), 1점(부분적으로 기여), 2점(충분히 기여) 중 하나를 선택하고, 팀원별로 판단 근거가 되는 작업이나 사례를 한 가지 이상 적으세요. 직접 확인할 근거가 부족한 항목은 ‘확인 어려움’으로 표시하세요.

유효한 평가 한 건의 6점 만점 합계에 5를 곱해 30점 만점으로 환산하고, 받은 환산 점수의 평균을 개인별 동료평가 점수로 반영합니다. 누락되었거나 근거가 부족한 평가, 평가자 간 판단 차이가 큰 경우에는 교수자가 역할 기록과 산출물을 확인해 점수를 확정합니다.

제출 전 점검

  • 공개 자료의 출처와 수집 맥락을 밝히고 질문 3개 이상을 정했다.
  • 재표현 전후를 확률플롯으로 비교하고 이원 분석에서 혼재변수를 검토했다.
  • 주요 결과 3건을 독립적으로 확인하고 검증 로그와 AI 대화 기록을 남겼다.
  • 노트북을 처음부터 재실행하고 발표 자료의 수치와 대조했다.
  • GitHub 노트북을 다른 사람이 열고 재현할 수 있는지 확인했다.
  • 최종 발표 후 본인을 제외한 팀원별 동료평가와 판단 근거를 개별 제출한다.
