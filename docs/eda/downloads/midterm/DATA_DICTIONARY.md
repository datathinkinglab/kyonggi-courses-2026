# 자료탐색방법론 중간고사 자료 사전

## 자료의 출처와 관측 단위
교수자가 중간고사 실습을 위해 구성한 교육용 가상 식당 방문 자료 120건입니다.
실제 학교 식당 조사 결과가 아니며 실제 학생이나 식당의 통계로 인용할 수 없습니다.
한 행은 방문 한 건입니다. 행 수를 학생 수로 해석하지 않습니다.
조사 날짜나 반복 방문자의 식별 정보는 제공하지 않습니다.

| 변수 | 의미 | 척도와 기록 규칙 |
| --- | --- | --- |
| visit_id | 방문 기록 식별자 | 명목, M001~M120, 중복 없음 |
| time_slot | 방문 시간대 구분 | 명목, 점심 초반 / 점심 혼잡 / 저녁, 결측 없음 |
| wait_minutes | 주문 후 음식 수령까지 기다린 시간(분) | 비율, 비음수 정수, 빈칸은 미응답 |
| satisfaction | 해당 방문의 만족도 | 순서, 1 매우 불만족~5 매우 만족, 빈칸은 미응답 |

## 처리 원칙
- 0분은 기다리지 않았다는 유효 관측값입니다. 빈칸과 구별합니다.
- 시간 미응답은 시간 평균·그림에서 제외하고 전체·유효·결측 수를 함께 보고합니다.
- 만족도만 미응답인 방문의 유효 시간은 시간 분석에 포함합니다.
- 큰 값은 그 자체로 오류나 삭제 대상이 아닙니다. 원자료를 보존하고 확인할 점을 설명합니다.
- 같은 시간값을 가진 서로 다른 방문은 각각의 관측값입니다. 값이 같다는 이유로 중복 제거하지 않습니다.
- 미응답 발생 이유와 표본 추출 과정에 대한 추가 정보는 없습니다. 한계를 밝히세요.
