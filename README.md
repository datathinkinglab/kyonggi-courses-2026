# 경기대학교 응용통계전공 강의 포털

## 배포 주소

- GitHub Pages 통합 포털: https://datathinkinglab.github.io/kyonggi-courses-2026/
- 통합 강의 포털: https://kyonggi-data-courses-2026.seungmook.chatgpt.site

## 폴더 구조

```text
portal/                              통합 강의 포털
courses/exploratory-data-analysis/  자료탐색분석 사이트
courses/statistical-consulting/     통계컨설팅의 이해 사이트
shared/                              공통 브랜드 자산
```

과목별 사이트는 서로 다른 Sites 프로젝트로 배포합니다. 따라서 한 과목의 주차별 자료를 수정해도 다른 과목의 배포에는 영향을 주지 않습니다.
